# Archiwum dokumentacji

Czytaj tylko wpisy potrzebne do zadania. Bieżące zasady pracy są w
[planie](../plan.md), konfiguracja i aktualizacja w [DEPLOY.md](../DEPLOY.md),
a uruchamianie i testowanie w [DEVELOPMENT.md](../DEVELOPMENT.md).

Przeniesienie zapisów nie zmienia zasad, statusów, wyników CI ani potwierdzeń
wdrożeń i prób telefonu. Archiwalne decyzje nadal stosuje się w zakresie,
w którym nie zastąpiła ich późniejsza decyzja. Nie wykonuj ponownie pierwszego
deployu D.1–D.4. Opisy przyszłych zakresów nie są poleceniem ich implementacji.
